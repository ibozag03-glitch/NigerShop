# Base de Données NigerShop

## Installation de la BD

### Option 1: Importer le script

1. Ouvrez phpMyAdmin: http://localhost/phpmyadmin
2. Cliquez sur "Importer" (en haut)
3. Sélectionnez le fichier `nigershop.sql`
4. Cliquez sur "Exécuter"
5. La BD est créée automatiquement!

### Option 2: Copier/Coller le script

1. Copier le script contenu dans le fichier `nigershop.sql`
2. Accédez à phpMyAdmin: http://localhost/phpmyadmin
3. Créez une nouvelle base de données nommée `NigerShop`
4. Allez à l'onglet SQL
5. Coller le script et cliquez sur "Exécuter"
6. Mission accomplie BD créée avec succès
